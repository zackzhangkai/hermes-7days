# Hermes Agent 7 Days 实战课程

> 从零开始，掌握开源 AI Agent 框架

🖥️ **在线课程网站**: https://hermes-7days.pages.dev

---

## 课程介绍

本课程面向希望掌握 Hermes Agent 的开发者，通过 8 节实战课程，层层递进地学习 Hermes Agent 的各项核心功能。

**课程特色：**
- 🛠️ 每节都有动手实战
- 📚 真实的案例驱动
- 🔰 从基础到生产部署
- 📝 完整的命令示例
- 🌐 支持 15+ 消息平台

---

## 课程大纲

| 课次 | 主题 | 核心内容 |
|:---:|------|---------|
| **Lesson 1** | Hermes Agent 基础与环境搭建 | 安装配置、架构概念、运行第一个 Agent |
| **Lesson 2** | Provider 配置与模型选择 | 18+ 提供商配置、免费模型、Failover |
| **Lesson 3** | Memory 持久化与跨会话记忆 | MEMORY.md、自动学习、跨会话记忆 |
| **Lesson 4** | Channel 消息通道配置 | Telegram、Discord、Slack 等 15+ 平台 |
| **Lesson 5** | Skill 系统与自定义技能 | 内置 Skills、自定义 Skill 开发 |
| **Lesson 6** | Gateway API 与 HTTP 接口 | REST API、Webhook、认证 |
| **Lesson 7** | Cron 定时任务与自动化调度 | 定时任务、任务队列、多 Agent |
| **Lesson 8** | 生产部署与运维 | Docker 部署、监控告警、高可用 |
